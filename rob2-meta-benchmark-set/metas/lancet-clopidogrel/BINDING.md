Contrast: Clopidogrel monotherapy vs aspirin monotherapy, IPD, intention-to-treat, longest available follow-up (abstract: 'At 5·5 years'; median 2·3 years). Per-trial populations in the meta (Table S7 p28; forest plots Figures S3-S7): ASCET 499 vs 502 (whole randomized trial, ~2 years); CADET 94 vs 90 (~0.4 patient-years each); CAPRIE 4242 vs 4204 = 8446, a subset of CAPRIE's 19,185 (Table S7: prior MI 8446 (100%); equals the trial's 6302 qualifying-MI + 2144 past-MI patients, CAPRIE p7-8); HOST-EXAM 2710 vs 2728 with ~4.9 patient-years each (extended follow-up beyond the 24-month report); SMART-CHOICE 3 2752 vs 2754 (ITT); STOPDAPT-2 1445 vs 1437 = 2882 (ITT 1-year report had 1500 vs 1509) with ~3.8 patient-years each (beyond the 1-year report); STOPDAPT-3 2765 vs 2760 = 5525 (30-day landmark ITT in the EHJ report had 2913 vs 2920 = 5833) with ~0.9 patient-years each.
