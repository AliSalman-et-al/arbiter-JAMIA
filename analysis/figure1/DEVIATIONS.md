# Figures 1–2: scope and display decisions

- **Ownership:** only `analysis/figure1/**`, Figure1/2 deliverables, their explicitly requested QA images, `figure1-notes.md` and `legends-fig1-2.md` are changed. The parent integrates legends; shared manuscript legends and supplementary material remain outside this task.
- **AVATAR retry correction:** one of seven save calls was rejected, as requested. The rejected D3 call put source/page/lines directly in the basis. Its successful retry nested the locator under `bases[].evidence`, an accepted source-span reference form; it did not send an `eh_…` string. The bound bundle evidence has handle `eh_e66d374e838e8c6d`. Exact IDs and basis objects are in `avatar-save-retry.json`. Figure 1's return label summarizes validation rather than asserting that handles are the only accepted syntax.
- **Quote transcription:** all selected wording was found in the bundle or logs. Display wraps collapse whitespace, and two extraction breaks are joined (`assign-\nment` → `assignment`, `cen\nsored` → `censored`). No scientific words are replaced. Omissions use ellipses. The notes preserve the full raw bound spans as well as the displayed excerpts. The D4 bound span does contain the DSMB unblinding sentence; no substitute citation was needed.
- **Evidence types:** yellow is direct support; lavender is context; an unfilled dashed outline is inference. D4's inference references the same underlying bound record but displays reasoning, not a source quotation. D5's absence statement remains plain text; its positive composite-outcome interpretation receives context highlighting.
- **Footnote comparison:** the Published/Adjudicators/Unassisted footer compares D5. Overall has the same Published and Unassisted labels, but was not adjudicated. The legend makes this distinction explicit.
- **Algorithm language:** the server computes a proposed judgement; the model may adopt a different judgement via a recorded override. AVATAR's D5 is adopted unchanged. The figure does not generalize this case's absence of override to all runs.
- **Typography:** the editable source scene and SVG use outlined bundled Fira fonts. The PDF contains selectable text with subset-embedded Fira TrueType fonts, satisfying the requested embedded-font deliverable; converter-added unused standard-font resources are removed. Both are vector-only.
- **Verification:** manifest hashes and data assertions run on every build. The displayed verifier result is the archived receipt, not a new verifier execution. Approximate display-RGB CVD proofs supplement greyscale checks; they are not calibrated clinical simulations.
- **Variants:** Figure 1 omits the benchmark count, which appears only in the legend; the former count variant is removed. The main Figure 2 includes the provisional Unassisted column. Its alternative reflows source cards to full width and shortens the page. All main figures retain the 174 mm width and ≥7 pt text.
- **Audit denominator:** rejection counts describe the specified Sonnet log tree only. Calls are unique tool-use IDs, with successful repeats retained. All 53 flagged results are error responses; 32 concern evidence/basis schema, 20 other schema/validation construction errors, and one malformed JSON input. No rejection is classified as an incorrect clinical judgement.

- **PI revision:** all requested changes are implemented. The sole layout deviation is that the Unassisted D4 and D5 explanatory notes wrap to two lines: the verbatim requested wording cannot fit a single line inside the 166-unit column at ≥7 pt. This keeps the intended wording, readability and clear gutter. Source quotes and rationale excerpts remain verbatim.
- **Recovery audit:** 47 trial-domain assessments had ≥1 rejected call and all 47 ended with accepted saves; all 510 domains had successful saves. Every rejection has a later accepted save for its domain. One PALOMA-2 rejection submitted only trial_id; its D1 attribution is inferred from the explicit D1 retries immediately before and after it and marked in the CSV. A malformed JSON rejection exposes its deviations domain literally in raw input.

Unknown text has a five-unit label gap and a hanging indent. Assessment black arrows move five units outward; the red return is straight and continuous from its pill through the server lane to the agent.
