## Figure 1. ARBITER workflow and evidence trace

**Figure 1. ARBITER workflow and evidence trace.** (A) A reviewer approves the result to be assessed before domain assessment starts. The LLM agent uses the arbiter-assess skill to read sources and answer RoB 2 signalling questions. The model-free ARBITER MCP server captures and versions sources, binds cited text spans, computes domain and overall judgements using the official RoB 2 algorithms, records the assessment history and exports a verifiable bundle. Representative MCP calls are shown in monospace on downward request arrows; upward arrows carry italic response summaries. Approval through `arbiter review` unlocks domain work; the reviewer receives a report and a `.arbiter.zip` bundle checked by an independent verifier. Tools used across phases are grouped by function in these notes. (B) AVATAR, all-cause death at long-term follow-up: the report describes time to death as prespecified, but the agent records no information for question 5.1 because the captured sources do not establish a plan for this measurement and analysis finalized before unblinded outcome data were available. Yellow highlighting links the report excerpt, recorded as context, to the passage-referencing words in the reasoning; the answer pill is neutral. The complete D5 answer set produces Some concerns, adopted without override. The hash prefix identifies the captured source projection; archived bundle verification confirms binding and structural checks, not the clinical correctness of the answer. Published and Unassisted judgements are Low; both adjudicators prefer Some concerns. D1–D5, RoB 2 domains; NI, no information; PN, probably no; MCP, Model Context Protocol.

Alt text: Two panels. A: Reviewer, lavender LLM agent, mint deterministic ARBITER server and pale-yellow bundle lanes span Capture, Propose and approve, Assess each domain, and Review and export. Reviewer approval via arbiter review unlocks domain work. The reviewer receives a report and verifiable .arbiter.zip bundle. Downward tool-call arrows and upward response arrows connect agent and server. The agent supplies cited answers; the server checks spans and computes judgements. B: AVATAR has Low judgements for D1–D4 and Some concerns for D5 and Overall. A cited passage calls time to death a prespecified secondary endpoint. Yellow links that quoted passage to the reasoning phrase “calls the endpoint prespecified”. A neutral pill gives question 5.1 as No information because a dated plan is not established by captured sources. D5 answers NI, PN, PN yield Some concerns, adopted unchanged. The passage is bound to a hashed captured source; archived bundle verification is verified. Published Low; adjudicators Some concerns; Unassisted Low.

## Figure 2. Benchmark inclusion and adjudication flow

Sixteen meta-analyses supplied 105 trials. Three unsupported-design trials were excluded from every arm and analysis, leaving 102 trials, 510 D1–D5 cells per arm and 81 trials with a Published Overall label. Of 154 disputed cells, 129 had consensus and 25 were split. The Sonnet arms differed on 62 consensus cells: 54 ARBITER wins, 7 Unassisted wins and 1 neither. Eighteen split cells also had differing arm judgements.

Alt text: Flow diagram from 105 trials to 102 included after three exclusions, then 154 disputed cells divided into 129 consensus and 25 split cells. The 62 differing consensus cells yield 54 ARBITER, 7 Unassisted and 1 neither win.

## Figure 5. Individually decisive signalling questions behind consensus losses

Paired ARBITER and Unassisted bars count individually decisive questions among consensus losses for which both adjudicators’ independent judgements equal the preferred judgement (10 ARBITER and 47 Unassisted losses). Domain facets give each source’s eligible loss count; question numbers and abbreviated RoB 2 text identify rows. A question is decisive when substituting the unanimously agreed independent answer alone changes the official algorithm output. A cell can contribute several questions. Jointly decisive sets contribute no individual-question counts. Zero-count bars and labels are omitted; ARBITER is above Unassisted and first in the legend. D2 uses effect of assignment.

Alt text: Domain facets compare decisive-question counts with paired bars. Question 5.1, whether the analysis plan was finalised before unblinding, contributes 18 Unassisted and 2 ARBITER counts. Question 2.3 contributes 3 for each source. Other displayed questions have counts from zero to three.
