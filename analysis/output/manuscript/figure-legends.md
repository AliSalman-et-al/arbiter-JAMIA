
**Figure 1. ARBITER splits the work: an AI model reads and answers; rule-based software checks quotes, applies RoB 2 rules and records everything.** Lanes show the reviewer, AI model, ARBITER server and audit file across capture, approval, domain assessment and export. Plain labels show actions; gray text names the underlying tool calls. The reviewer receives the HTML report and audit file, both checkable by an independent verifier. RoB 2 is the Cochrane risk-of-bias tool for randomised trials.

Alt text: The reviewer chooses a trial and outcome and approves the result to assess. The AI model reads reports, selects evidence and answers questions. ARBITER stores source records, checks quotes and applies the RoB 2 rules. The reviewer receives an HTML assessment report and an audit file containing sources, quotes, answers and decisions; both can be checked by an independent verifier.

**Figure 2. This trial was chosen to illustrate the process, not as representative. Rows link paraphrased questions, source excerpts, AI answers, software checks and domain ratings. Letter/page tabs identify sources; “Weighed against” and “Open point” give counter-evidence and unknowns. A missing dated analysis plan leads to Some concerns overall. Full answers and official question wording appear in the linked repository AVATAR answer and evidence records. Y, yes; PY, probably yes; PN, probably no; N, no; NI, no information. The footer compares the Published D5 label with the subsequent blinded D5 choices from both human reviews; it does not report independently rated Overall judgments.

Alt text: AVATAR's five risk-of-bias domains connect source excerpts to the AI model's answers and the ratings computed by ARBITER. Four domains are Low. For selection of the reported result, the stored sources do not establish a dated plan for this analysis. The model answers No information, and the RoB 2 rules yield Some concerns for that domain and overall. Counter-evidence and unresolved questions remain visible alongside the answers.

Figure 3. Paired evaluation and conditional blinded-label choices. Both arms assessed the same 102 trials using the same reported model identifier and supplied documents. Two human reviewers independently recorded ratings and signalling answers for all 510 trial-domain cells before viewing labels. In a separate stage, each chose among three labels presented in random order without rationales. The conditional choice estimate uses 60 agreed choices from 80 arm-cells where the two arms disagreed; 20 split choices enter sensitivities. The all-cell human reviewer comparisons are not restricted to that conditional population. Counts are trials or cells as indicated; no interval applies.

Figure 4. Absolute and paired domain agreement with each independent human reviewer. Blue circles denote ARBITER and orange squares Unassisted. Left panels show exact agreement with 95% intervals on a 0–100% scale; right panels show paired ARBITER minus Unassisted differences in percentage points, with neutral diamonds and zero lines. Each human reviewer contributes 510 pooled cells and 102 per domain. Between human reviews agreement is 388/510 (76.1%; weighted κ 0.59), context rather than a performance ceiling. The compact Published comparison retains all 510 cells. D1: randomisation process; D2: deviations from intended interventions; D3: missing outcome data; D4: outcome measurement; D5: selection of the reported result.  CI, 95% confidence interval; 10,000 percentile bootstrap replicates, trials resampled within meta-analysis; seed 20261018.
