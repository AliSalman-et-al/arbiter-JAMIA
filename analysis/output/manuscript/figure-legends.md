# Legends and alt text: Figures 1–2

**Figure 1. ARBITER splits the work: an AI model reads and answers; rule-based software checks quotes, applies RoB 2 rules and records everything.** Lanes show the reviewer, AI model, ARBITER server and audit file across capture, approval, domain assessment and export. Plain labels show actions; grey text names the underlying tool calls. The reviewer receives the HTML report and audit file, both checkable by an independent verifier. RoB 2 is the Cochrane risk-of-bias tool for randomised trials.

Alt text: The reviewer chooses a trial and outcome and approves the result to assess. The AI model reads reports, selects evidence and answers questions. ARBITER stores source records, checks quotes and applies the RoB 2 rules. The reviewer receives an HTML assessment report and an audit file containing sources, quotes, answers and decisions; both can be checked by an independent verifier.

**Figure 2. Each answer is tied to stored sources, and RoB 2 rules compute the rating across every domain.** AVATAR compares early surgery with watchful waiting in asymptomatic severe aortic stenosis; the outcome is all-cause death. This trial was chosen to illustrate the process, not as representative. Rows link paraphrased questions, source excerpts, AI answers, software checks and domain ratings. Letter/page tabs identify sources; “Weighed against” and “Open point” give counter-evidence and unknowns. A missing dated analysis plan leads to Some concerns overall. Full answers and official question wording appear in the AVATAR complete trace in the supplement. Y, yes; PY, probably yes; PN, probably no; N, no; NI, no information.

Alt text: AVATAR's five risk-of-bias domains connect source excerpts to the AI model's answers and the ratings computed by ARBITER. Four domains are Low. For selection of the reported result, the stored sources do not establish a dated plan for this analysis. The model answers No information, and the RoB 2 rules yield Some concerns for that domain and overall. Counter-evidence and unresolved questions remain visible alongside the answers.
