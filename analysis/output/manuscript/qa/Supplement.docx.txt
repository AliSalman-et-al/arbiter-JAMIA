ARBITER: Supplementary material
Methods appendix
Algorithms and validation
The official 22 August 2019 RoB 2 algorithms were implemented for D1 randomisation, D2 deviations (effect of assignment), D3 missing outcome data, D4 outcome measurement and D5 selection of the reported result. Numbered questions map to the 22 exported signalling questions. Required NA or missing answers make a nonempty path invalid; absent labels or wholly absent answer sets are not evaluable. Overall is the worst domain judgement, with High permitted when at least two domains have Some concerns. The guidance was cross-checked with ARBITER 1.0.0 source (commit 2f549ae). Unit tests cover the decision paths and required-answer checks. Bundle proposals reproduce 510/510 Sonnet and 505/505 observed Haiku domain outputs. One Haiku adoption overrides a Low proposal to Some concerns; rationale and evidence are retained. All required active answers in the ARBITER domain histories are present. Unassisted invalid-path sensitivity recursively resolves required invalid answers as N/PN, then NI; off-path answers are not imputed.
API list-price reconstruction
Costs are frozen-rate API list-price equivalents, not expenditure. USD rates per million tokens are: Sonnet input 2.00, 1-hour cache write 4.00, 5-minute write 2.50, cache read 0.10, output 10.00; Haiku at prompts of at most 100,000 tokens: 0.10, 0.20, 0.125, 0.01, 0.50; above 100,000: 0.50, 1.00, 0.625, 0.05, 2.50. Rates were frozen from the provider pricing documentation on 18 October 2026. Main-thread assistant events are deduplicated by message identity within turn; synthetic zero-usage events are excluded. Prompt length is input plus cache creation plus cache read. Terminal output is allocated by request share for the point estimate and wholly to lower/higher tiers for bounds. Thinking tokens are already included in output. Signed terminal-minus-request input residuals, including negative retry residuals, are retained and allocated at lower-tier, request-share and higher-tier rates. Side calls are modelUsage minus terminal usage. Compaction uses high-tier pricing and one-hour writes; five-minute writes are a sensitivity. Side-call turns without a compaction boundary are flagged and bounded. All trial bounds are ordered; Sonnet bounds coincide. Routing was global, with no geography multiplier. Harness costs are unusable: unrecognised model and unknown cost basis; retained only as supplementary diagnostics.
Error localisation
Losses are consensus cells where a source label differs from preferred. A reference adjudicator is usable only when their independent judgement equals consensus preferred. Primary requires both; sensitivity at least one. Haiku is excluded. Y/PY collapse to Y and N/PN to N; NI and NA remain separate. Discordance requires all usable adjudicators to agree on a parsed answer different from the losing answer. Adjudicator disagreements are separately flagged, never errors. A single replacement is decisive if it changes a valid algorithm output, even if the new output is not preferred. Other answers, including inactive NA, stay fixed; invalid substituted paths are not decisive. First applicable cell class: judgement departs from own answers; single decisive question; several decisive questions; jointly decisive (all discordant replacements reach preferred); no discordant questions with complete comparisons; not attributable. The no-discordance class can contain adjudicator-disagreement questions. Reference-judgement departures from their own answers are flagged. Frequencies count all individually decisive questions regardless of cell class; joint sets contribute none. Ambiguous or qualified answers are not imputed. Published losses cannot be localised without signalling answers.
Evidence binding and verification
Each distinct evidence identity cited in bases or counterevidence by current active answers is counted once per bundle; superseded histories are excluded. Visual records (figure kind or render field) take precedence over text spans. Text spans (narrative kind or quote/start/end fields) require a nonblank quote and source version, source identity matching a captured bundle source, finite page/start/end, and start less than end. Quotes are server-extracted spans cited by handle. Visual binding requires render source matching the record and a captured source, positive integer page, nonblank PNG hash, four finite region coordinates in [0,1] with ordered corners, and nonblank transcription. Images are server-rendered and hash-bound; transcriptions are model-written and are not machine-checked against the image. Unknown or missing records are other and unbound in the overall denominator. Empty bundles contribute no cited records. Trials using visual evidence use all 102 trials as denominator. These are structural checks, without PDF re-extraction or a judgement of whether a passage supports an answer. Bundle verification does not establish clinical correctness or completion. Unassisted evidence traces are not available.
Inference and references
All estimates use the fixed 102-trial set. CIs use 10,000 trial-cluster bootstrap replicates stratified by meta-analysis, percentile intervals (quantile type 7), seed 20261018; the same weights support paired differences. Missing predictions count as wrong. For ordinal coefficients a missing prediction receives maximal disagreement; a paired observed-cell Haiku sensitivity is reported. Independent signalling-answer agreement uses the earlier exploratory Y/PY, N/PN and NI/NA collapse. RoB 2 guidance: https://www.riskofbias.info/welcome/rob-2-0-tool/current-version-of-rob-2. ARBITER source: https://github.com/AliSalman-et-al/ARBITER/tree/2f549ae30f056ff441ea61a04b719968716f2219. Pricing source: https://platform.claude.com/docs/en/about-claude/pricing.

ARBITER example
/arbiter-assess Assess risk of bias for Adverse events graded by CTCAE v4.0; 'Grade 3 (severe AEs)' row of Table 3; patients with grade 3 events in Table 4 defined as Table 3 Grade 3 (severe AEs) number of AEs: 600 mg 6, 900 mg 5, 1,200 mg 9 (all subjects 20); Grade 4: 0; Grade 5 (death): 1 per arm. Table 4 total no. of patients with grade 3 events: 2, 4, 5. Abstract: 'Grade 3 adverse events occurred in only 2 patients in the 600-mg arm, 4 patients in the 900-mg arm, and 5 patients in the 1,200-mg arm.' in aarnoutse-2017.

Unassisted output-format instruction
When you have finished, give your answers in this format: a table with one row per signalling question (columns: domain, question number, answer as Y, PY, PN, N, NI or NA), and then a final line exactly like "FINAL: D1=<judgement>; D2=<judgement>; D3=<judgement>; D4=<judgement>; D5=<judgement>; Overall=<judgement>", where each judgement is Low, Some concerns or High.
Run provenance
Models claude-sonnet-5-5 and claude-haiku-5-5; effort medium; Claude Code 2.1.278; isolated configuration homes. ARBITER 1.0.0, public commit 2f549ae30f056ff441ea61a04b719968716f2219. ARBITER with Sonnet ran 12 October 2026 (12:12-19:17 EDT); other arms ran 14 October 2026. Harness approved the proposed result unchanged and replied Approved.; uncoached Continue. replies were permitted at most twice per phase. Each trial ran once in each arm; run-to-run variability is not estimated. Unassisted access was limited to Read, Glob and Grep, without an MCP server, skills or web tools. Supplied registry Markdown and acquired protocol/SAP documents preserved input parity. Trial PDFs are not redistributed; source DOIs and FILES.csv hashes identify them. Bootstrap seed 20261018, 10,000 replicates; R/renv/Quarto versions are recorded in the project lockfile and session-info.txt.
